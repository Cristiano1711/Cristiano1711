## 🚀 Projetos em Destaque

### 🎮 [Dashboard de Games](https://github.com/Cristiano1711/dashboard-games) — [ver ao vivo](https://dashboard-games.vercel.app)

> Dashboard interativo com dados reais de jogos: busca, filtros, estatísticas em gráficos e favoritos

- **Full-stack**: frontend em React + Vite e backend próprio em Node/Express atuando como proxy e cache
- **Integração com API externa** (IGDB, da Twitch) autenticada via OAuth2
- **Migração de API em produção** (RAWG → IGDB), documentada no repositório
- **Deploy real**: frontend na Vercel e backend no Render

`React` `Vite` `Node.js` `Express` `OAuth2` `REST`

---

### ⚓ [Batalha Naval — Multiplayer via Sockets TCP em C](https://github.com/Cristiano1711/Batalha-Naval-Threads-TCP)

> Jogo de Batalha Naval multijogador em tempo real com arquitetura cliente-servidor

- **Servidor** multithreaded com threads e controle de concorrência via mutex
- **Protocolo de comunicação** textual customizado sobre TCP
- **Visualização em terminal** com duas matrizes 8×8 renderizadas em tempo real com cores ANSI
- Separação clara de responsabilidades: lógica de jogo, rede e interface em módulos independentes

`C` `Sockets TCP` `Pthreads` `Mutex` `Linux` `Makefile`

---

### 🎫 [SGIR — Sistema de Gestão de Incidentes e Requisições](https://github.com/Cristiano1711/Sistema-de-Gestao-de-Incidentes-e-Requisicoes-SGIR-)

> Gerenciador de tickets de suporte técnico full-stack com ciclo de vida completo de chamados

- **Arquitetura MVC** com Flask, rotas RESTful e gerenciamento de estado (Aberto → Em Andamento → Fechado)
- **Persistência híbrida**: MySQL relacional para dados estruturados + JSON nativo para histórico de comentários
- **Front-end** responsivo, CSS Grid e Flexbox — zero dependência de frameworks externos
- Lógica de ownership: técnicos assumem chamados e o dashboard reflete as transições em tempo real

`Python` `Flask` `MySQL` `HTML` `CSS`
